# MindSync Enterprise

Workplace wellbeing intelligence platform — PySide6 desktop app + Text, Video/Facial-Emotion-Behavior, Audio, and DSI-Fusion AI services.

## Structure
- `app/` — desktop UI, services, database, core, utils
- `ai_services/` — text, video/facial-emotion-behavior, audio, dsi-fusion
- `data/`, `models/`, `tests/`, `scripts/`, `docs/`

See `docs/setup_guide.md` for setup.
